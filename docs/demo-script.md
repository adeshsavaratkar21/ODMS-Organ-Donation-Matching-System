# ODMS Demo Script (target: 3 minutes)

**0:00–0:20 — Sign in**  
Open the app and sign in with the local demo administrator account. Mention that all data is synthetic.

**0:20–0:40 — Dashboard**  
Point out the database-backed counts for donors, available organs, active waitlist, and pending reviews.

**0:40–1:10 — Donor registry**  
Show donor records, search/filter, and register one synthetic donor. Save it and show that it appears in the list.

**1:10–1:40 — Recipient waitlist**  
Add a synthetic recipient for the same organ type and choose a blood group compatible under the simplified demo rules. Save the record.

**1:40–2:20 — Matching engine**  
Select an available donor and run matching. Explain the organ-type filter, simplified ABO screening, and transparent demo ranking. Show candidate explanations and the clinical-review warning.

**2:20–2:45 — Review and history**  
Review a result, save a demo status, then open Match History to show that the run persists.

**2:45–3:00 — Notifications and audit trail**  
Show in-app notifications and privileged audit records. Close by stating that the system is an educational prototype, not a clinical allocation system.
